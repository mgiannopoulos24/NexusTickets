# NexusTickets

Πλατφόρμα διαχείρισης εκδηλώσεων και ηλεκτρονικών κρατήσεων εισιτηρίων, που αναπτύχθηκε ως υποχρεωτική εργασία για το μάθημα "Τεχνολογίες Εφαρμογών Διαδικτύου" (ΣΤ' εξάμηνο), Τμήμα Πληροφορικής και Τηλεπικοινωνιών.

## Επισκόπηση

Το NexusTickets είναι μια full-stack εφαρμογή ιστού που επιτρέπει στους διοργανωτές να δημιουργούν και να διαχειρίζονται εκδηλώσεις, στους συμμετέχοντες να πλοηγούνται και να κάνουν κρατήσεις εισιτηρίων, και στους διαχειριστές να εποπτεύουν την πλατφόρμα. Το σύστημα βασίζεται σε αρχιτεκτονική client-server και είναι προσβάσιμο αποκλειστικά μέσω του προγράμματος περιήγησης.

Η πλατφόρμα υποστηρίζει τέσσερις διαφορετικούς ρόλους: Διαχειριστής, Διοργανωτής, Συμμετέχων και Επισκέπτης. Η πρόσβαση στις λειτουργίες καθορίζεται σε επίπεδο API μέσω αυθεντικοποίησης JWT και εξουσιοδότησης βάσει ρόλου.

## Τεχνολογικό Πλαίσιο

### Νοτιαίο Άκρο (Backend)
- **Γλώσσα**: Go 1.22+
- **HTTP Framework**: Fiber v2
- **ORM**: GORM με PostgreSQL driver
- **Έγχυση Εξαρτήσεων**: Wire (compile-time)
- **Αυθεντικοποίηση**: JWT (ζεύγος access + refresh token)
- **Δομημένη Καταγραφή**: Zap

### Βάση Δεδομένων
- **Κύρια Αποθήκευση**: PostgreSQL 16
- **Cache / Αποθήκευση Συνεδριών**: Redis 7

### Μετωπιαίο Άκρο (Frontend)
- **Framework**: React 19
- **Εργαλείο Build**: Vite 8+
- **Διαχειριστής Πακέτων / Runtime**: Bun
- **Γλώσσα**: TypeScript 5+ (strict mode)
- **Στυλιστική Διαμόρφωση**: Tailwind CSS v4
- **Στοιχεία Διεπαφής**: shadcn/ui (Radix primitives + Tailwind)
- **Εικονίδια**: Lucide React
- **Δρομολόγηση**: React Router v7
- **Διαχείριση Κατάστασης**: Redux Toolkit + RTK Query
- **Φόρμες**: React Hook Form + Zod

## Εγκατάσταση για Τοπική Ανάπτυξη

### Προαπαιτούμενα

- Docker και Docker Compose
- Go 1.22+
- Bun 1.x
- Make

### Εκτέλεση με Docker Compose

```bash
# Αντιγραφή template περιβάλλοντος και συμπλήρωση τιμών
cp .env.example .env

# Εκκίνηση όλων των υπηρεσιών (PostgreSQL, Redis, backend, frontend)
docker compose -f docker-compose.yml -f docker-compose.dev.yml up
```

Το frontend είναι διαθέσιμο στο `http://localhost:5173`.  
Το backend API είναι διαθέσιμο στο `http://localhost:8080/api/v1`.  
Η τεκμηρίωση API βρίσκεται στο `http://localhost:8080/api/v1/docs`.

### Εκτέλεση Χωρίς Docker

```bash
# Backend
cd backend
go mod download
make migrate-up
make dev

# Frontend (ξεχωριστό terminal)
cd frontend
bun install
bun run dev
```

## Επισκόπηση API

Όλα τα endpoints έχουν πρόθεμα `/api/v1/`. Η αυθεντικοποίηση χρησιμοποιεί Bearer tokens που περνούν στην κεφαλίδα `Authorization`.

Δημόσια endpoints (χωρίς απαίτηση αυθεντικοποίησης):

```
POST   /auth/register
POST   /auth/login
POST   /auth/refresh
GET    /events
GET    /events/:id
```

Όλα τα υπόλοιπα endpoints απαιτούν έγκυρο JWT και κατάλληλο ρόλο. Βλέπε `docs/api.md` για τον πλήρη χάρτη διαδρομών.

## Βασικά Χαρακτηριστικά

**Διαχείριση εκδηλώσεων**: Οι διοργανωτές δημιουργούν εκδηλώσεις με πολλαπλούς τύπους εισιτηρίων, έλεγχο χωρητικότητας, κατηγορίες, γεωτοποθεσία και προαιρετικές συλλογές φωτογραφιών. Οι εκδηλώσεις ακολουθούν κύκλο ζωής: Πρόχειρο, Δημοσιευμένο, Ολοκληρωμένο, Ακυρωμένο.

**Σύστημα κρατήσεων**: Ατομική μείωση χωρητικότητας αποτρέπει υπερκράτηση υπό ταυτόχρονα αιτήματα. Οι κρατήσεις επιβεβαιώνονται αμέσως κατά την υποβολή και δεν μπορούν να αναιρεθούν από τον συμμετέχοντα.

**Ανταλλαγή μηνυμάτων**: Οι διοργανωτές και οι συμμετέχοντες επικοινωνούν μέσω συστήματος εισερχομένων/απεσταλμένων μηνυμάτων. Η ακύρωση εκδήλωσης ενεργοποιεί μαζικές ειδοποιήσεις προς όλους τους εγγεγραμμένους συμμετέχοντες.

**Σύστημα συστάσεων**: Οι αυθεντικοποιημένοι χρήστες λαμβάνουν εξατομικευμένες προτάσεις εκδηλώσεων βάσει του ιστορικού κρατήσεων και της συμπεριφοράς περιήγησής τους, μέσω μοντέλου Biased Matrix Factorization που εκπαιδεύεται περιοδικά. Νέοι χρήστες λαμβάνουν συστάσεις βάσει δημοτικότητας.

**Εργαλεία διαχειριστή**: Ο διαχειριστής διαχειρίζεται εγγραφές χρηστών (έγκριση ή απόρριψη) και μπορεί να εξάγει τον πλήρη κατάλογο εκδηλώσεων σε μορφή XML ή JSON σύμφωνα με το DTD της εκφώνησης.

**Ενσωμάτωση χάρτη**: Οι σελίδες λεπτομερειών εκδήλωσης εμφανίζουν διαδραστικό χάρτη OpenStreetMap με δείκτη στην τοποθεσία της εκδήλωσης.
