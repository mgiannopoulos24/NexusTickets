# i18n Rules — NexusTickets React

## Language Strategy
- **UI language**: Greek (el) — primary and only required locale
- **Backend communication**: always English (API field names, error codes, enums, logs)
- **No runtime locale switching** required — Greek-only UI is sufficient for the assignment

## No i18n Library Needed
For this project scope (single language), use a simple centralized strings pattern instead of i18next or react-intl. This avoids overhead while keeping all user-facing text organized and easy to find.

```
src/
  lib/
    i18n/
      ui.ts          # All UI labels, placeholders, headings
      errors.ts      # Validation errors + API error code mapping
      messages.ts    # Success/info messages, confirmations
```

## Usage in Components
```tsx
// Import from i18n — never hardcode Greek strings in JSX
import { UI } from '@/lib/i18n/ui';
import { MESSAGES } from '@/lib/i18n/messages';
import { getApiErrorMessage } from '@/lib/i18n/errors';

// Good
<Button>{UI.actions.bookNow}</Button>
<p className="text-muted-foreground">{UI.emptyStates.noEvents}</p>

// Good — dynamic status label
<Badge>{UI.status.event[event.status]}</Badge>

// Good — API error display
const errorMessage = getApiErrorMessage(error.data?.error ?? 'internal_error');
<p className="text-destructive">{errorMessage}</p>

// BAD — hardcoded string in JSX
<Button>Κράτηση τώρα</Button>
```

## Pluralization Helper
```typescript
// lib/i18n/ui.ts — add plural helper
export function plural(count: number, one: string, many: string): string {
  return count === 1 ? `${count} ${one}` : `${count} ${many}`;
}

// Usage
plural(availableCount, 'διαθέσιμο εισιτήριο', 'διαθέσιμα εισιτήρια')
// → "1 διαθέσιμο εισιτήριο" or "5 διαθέσιμα εισιτήρια"
```

## Date, Time & Number Formatting
```typescript
// lib/utils.ts — centralized formatters, always Greek locale

export function formatDate(date: string | Date): string {
  return new Intl.DateTimeFormat('el-GR', {
    day: 'numeric', month: 'long', year: 'numeric',
  }).format(new Date(date));
  // → "12 Ιουλίου 2025"
}

export function formatDateTime(date: string | Date): string {
  return new Intl.DateTimeFormat('el-GR', {
    day: 'numeric', month: 'long', year: 'numeric',
    hour: '2-digit', minute: '2-digit',
  }).format(new Date(date));
  // → "12 Ιουλίου 2025, 20:30"
}

export function formatShortDate(date: string | Date): string {
  return new Intl.DateTimeFormat('el-GR', {
    day: '2-digit', month: '2-digit', year: 'numeric',
  }).format(new Date(date));
  // → "12/07/2025"
}

export function formatCurrency(amount: number): string {
  return new Intl.NumberFormat('el-GR', {
    style: 'currency', currency: 'EUR',
  }).format(amount);
  // → "18,00 €"
}

export function formatNumber(n: number): string {
  return new Intl.NumberFormat('el-GR').format(n);
  // → "1.000"
}
```

## Rules for AI-Generated Code
- Never hardcode a Greek string directly in JSX — always reference `UI.*`, `MESSAGES.*`, or `VALIDATION.*`
- Never hardcode an English-facing error message in a component — always use `getApiErrorMessage()`
- All date/time display must go through `formatDate`, `formatDateTime`, or `formatShortDate` from `lib/utils.ts`
- All currency display must go through `formatCurrency`
- Plurals always use the `plural()` helper — never ternary with hardcoded strings inline
- When adding a new user-facing string, add it to the appropriate `lib/i18n/*.ts` file first, then reference it
